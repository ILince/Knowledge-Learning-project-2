Sets the value of a custom HTML attribute that will be added when rendering the field.

public setHtmlAttribute(string $attributeName, mixed $attributeValue) : self

E.g. setHtmlAttribute('data-foo', 'bar') will render a 'data-foo="bar"' attribute in HTML. On 'index' and 'detail' pages, the attribute is added to the field container ( and div.field-group respectively). On 'new' and 'edit' pages, the attribute is added to the form field; it's a shortcut for the equivalent setFormTypeOption('attr.data-foo', 'bar).
